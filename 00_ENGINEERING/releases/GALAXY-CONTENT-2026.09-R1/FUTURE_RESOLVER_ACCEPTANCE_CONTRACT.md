# Future Resolver Acceptance Contract — Candidate Only

This is an acceptance contract for a later, separately authorized Resolver implementation. It is not executable code or an active schema.

After approved resource activation, a new Story run must: 1) expose the Map inventory before Story Conception; 2) permit discovery/selection of L01–L06 as provisional persistent-place identities, with no hard character/location gates; 3) keep L07 inventory-visible and non-selectable while source status is `UNDECIDED`; 4) expose L08 as a Personal State/user-space candidate while excluding it from ordinary physical-location selection and inferring no runtime semantics; 5) make Prehistory H01–H12 available only as authoring-background continuity under `AUTHORING_BACKGROUND_ONLY_UNTIL_EXPOSURE_REVIEW`; 6) grant no direct character/user disclosure permission; 7) block new runs when required active resources are missing or hash-drifted; and 8) leave historical run snapshots unchanged.

No Curriculum projection, Reference Asset Registry, Resolver, or Plan B consumer is activated by this contract.

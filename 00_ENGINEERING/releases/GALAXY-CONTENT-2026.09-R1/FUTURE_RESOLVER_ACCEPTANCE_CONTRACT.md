# Future Resolver Acceptance Contract

This is an acceptance contract for a later, separately authorized Story Kernel Resolver implementation. It is not executable code and does not itself activate a consumer.

Given `GALAXY-CONTENT-2026.09-R1`, a new Story run using the future Resolver must:

1. externally pin the exact Resource Catalog revision;
2. expose the Map inventory before Story Conception;
3. permit discovery/selection of L01–L06 as provisional persistent-place identities, with no hard character/location gates;
4. keep L07 inventory-visible and non-selectable while source status is `UNDECIDED`;
5. expose L08 as a Personal State/user-space candidate while excluding it from ordinary physical-location selection and inferring no runtime semantics;
6. make Prehistory H01–H12 available only as authoring-background continuity under `AUTHORING_BACKGROUND_ONLY_UNTIL_EXPOSURE_REVIEW`;
7. grant no direct character/User disclosure permission;
8. block new runs when required active resources are missing or hash-drifted;
9. preserve reproducibility for deterministic review-support dependencies such as the active Spoken View renderer and integrated-review template;
10. leave historical run snapshots unchanged.

Curriculum projection and Approved Reference Asset Registry are not activated by this release.
